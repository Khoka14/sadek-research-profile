# Sadek Hossain Khoka — Research Profile

A Python/Streamlit research and analytics portfolio website.

## Run locally

1. Install Python.
2. Open Command Prompt/PowerShell in this folder.
3. Install packages:

```bash
pip install -r requirements.txt
```

4. Run:

```bash
streamlit run app.py
```

5. Your browser should open the website automatically.
